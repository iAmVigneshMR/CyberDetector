The feed is downloaded every 6 hours and matched inside your browser — no browsing data is sent.

Create a key in Google Cloud Console → enable “Safe Browsing API”. Google has marked the v4 API used here as deprecated and it is licensed for non-commercial use only — commercial products should use Google's Web Risk API instead.

Works without a key (about 250 lookups per 5 minutes). PhishTank currently has new registrations disabled.

Deepfake & AI-media detection

Without a provider, media scans use metadata (EXIF, XMP, C2PA), generator fingerprints and error level analysis — useful, but they can't detect a well-made deepfake with stripped metadata. A detection API adds model-based scoring.

Open-source detection models running on your own machine — free, unlimited, and media never leaves your computer. Start it once with:

cd cyberDetector/detector-server
./setup.sh      # first time only (~2 GB download)
./run.sh        # prints the access token

Accuracy is lower than commercial services, especially on brand-new generators — see detector-server/README.md for measured results.

Uses the genai and deepfake models. Video is checked with the synchronous API, which accepts clips under 60 seconds.

Needs a v2 project API key for Hive's AI-generated content detection (Enterprise / project keys). Self-serve “V3” playground keys use a different API and will be rejected. Audio requires the audio model on your plan.

Receives multipart/form-data with file, mediaType, sourceUrl. Must return JSON: { "score": 0.92, "frames": [{"time": 1.5, "score": 0.8}], "regions": [{"x":0.1,"y":0.2,"w":0.3,"h":0.3,"score":0.9}] }

Privacy With a provider configured, scanned media is sent to that service. Only media you explicitly scan is ever sent.

Keys API keys entered here are stored in the browser and are fine for personal use. If you distribute this extension to others, never ship your keys inside it — run a small proxy server and point the Custom endpoint at it instead.

Embedded content in scanned media

When you scan an image, also look for scam content inside it. Decoding and text recognition run entirely in your browser.

Link checks use the same sources as manual URL scans: the local OpenPhish feed, plus Safe Browsing / PhishTank / crt.sh if you enabled them above. Shortened links are expanded (cookies omitted).
